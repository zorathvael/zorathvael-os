# Zorathvael OS — Mission Control Platform Design System

## Theme Selection
- **Theme Name**: Obsidian Command Deck (Enterprise High-Tech Cybernetics)
- **Probability**: 0.05
- **Design Movement**: Cyber-Industrial Dataism / Glassmorphism Enterprise
- **Core Principles**:
  1. High-Density Operational Visibility: Real-time telemetry, mission statuses, and multi-agent topology in a unified dark-mode cockpit.
  2. Fluid Architectural Hierarchy: Seamless switching between Executive Overview, Mission Center, Workforce Monitor, Workflow Visualizer, Plugin Control, and Memory Explorer.
  3. Tactical Micro-Interactions: Subtle glows, live status pulse indicators, and instant keyboard navigation.
  4. Uncompromising Contrast: Deep obsidian backgrounds with neon cyan, emerald green, and amber warning accents for instant operational clarity.

## Color Philosophy
- Background: Deep Obsidian `#090a0f` to `#11131a`
- Primary Accent: Cyber Cyan `#00f0ff` / Electric Blue `#3b82f6`
- Status Indicators: Emerald Green `#10b981` (Healthy), Amber `#f59e0b` (Warning), Crimson `#ef4444` (Critical/Error)
- Borders & Glass: Translucent white borders (`border-white/10`) with backdrop blur (`backdrop-blur-xl`)

## Typography System
- Display / Headers: JetBrains Mono / Inter (Bold, Tracking-tight)
- Body: Inter (Clean, legible at small sizes)
- Data / Metrics: Monospace font for telemetry and logs

## Signature Elements
1. Command Bar & Global Telemetry Ticker
2. Interactive Org Topology Tree (Executive Board -> Departments -> Workers)
3. Live Mission Execution Pipeline Progress Bar
4. Real-time Log Stream Terminal with Search & Filter
